# Lake Austin SEO Keyword Strategy

**Scope:** Boat Bros only services **Lake Austin**. This list prioritizes high-traffic, high-intent keywords that include "Lake Austin" (or Austin + boat context) so we rank for the right audience.

---

## Tier 1 – Primary (highest traffic, go after first)

| Keyword | Notes |
|--------|--------|
| **Lake Austin boat rentals** | Core head term; use in H1, title, meta, hero. |
| **Boat rentals Lake Austin** | Same intent, different word order; use in titles/descriptions. |
| **Lake Austin pontoon rentals** | Strong volume; pontoon is your main offer. |
| **Pontoon rentals Lake Austin** | Same; use on pontoon page and experiences. |
| **Lake Austin boat rental** | Singular; use in meta and body copy. |

## What to avoid

- **Generic “boat rentals”** without Lake Austin or Austin – attracts wrong geography.
- **Other lakes** (Travis, LBJ, etc.) – you don’t service them; don’t target them.
- **Stuffing** – use each phrase naturally 1–2 times per page; focus on clarity and intent.

Use this list to choose which phrases to add to titles, descriptions, headings, and body copy on each page. Prioritize Tier 1 and 2 for the main pages and Tier 3–4 for long-tail and blog/FAQs.
